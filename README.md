# 📓 Prompt Diary

Дневник промптов — коллекция 50+ экспериментов с LLM в процессе
обучения профессии промпт-инженера. Каждый ноутбук = одна техника,
живой вызов API, вывод модели и инсайт.

## Цель
Изучить и задокументировать основные и продвинутые техники промптинга
на практике — от zero-shot до ReAct и мета-промптинга.

## Стек
- Python 3.12 + Jupyter Notebook (VS Code)
- Groq API (llama-3.3-70b-versatile)
- Git + GitHub

## Техники

| # | Техника | Инсайт | Статус |
|---|---------|--------|--------|
| 01-02 | Zero-shot | Работает для простых задач, ломается на неоднозначных | ✅ |
| 03-04 | Few-shot | 3 примера решают то что zero-shot не может | ✅ |
| 05-06 | Chain-of-Thought | Пошаговое рассуждение устраняет задачи-ловушки | ✅ |
| 07-08 | XML вывод | XML как форма — модель заполняет поля, не галлюцинирует | ✅ |
| 09 | Prefill | Самый простой способ гарантировать формат | ✅ |
| 10 | Role prompting | Роль меняет не только стиль но и содержание | ✅ |
| 11-12 | Negative prompting | Оптимально 2-3 запрета, больше — модель ищет синонимы | ✅ |
| 13-14 | Structured JSON | XML на входе + JSON шаблон = надёжный парсинг | ✅ |
| 15-16 | System prompt | System prompt задаёт рамки, user работает внутри них | ✅ |
| 17-18 | Температура | Влияет на структуру больше чем на креативность | ✅ |
| 19-20 | Комбинация техник | Каждая техника закрывает слабость другой | ✅ |
| 21-22 | Prompt Chaining | Память создаёшь ты — передавая историю в messages | ✅ |
| 23-24 | Tree-of-Thought | Нужен для выбора между вариантами, избыточен для фактов | ✅ |
| 25-26 | Self-consistency | Few-shot CoT + голосование = максимальная надёжность | ✅ |
| 27-28 | Meta-prompting | Модель знает что делает хороший промпт лучше нас | ✅ |
| 29-30 | Persona-driven | Persona задаёт точку зрения и границы компетентности | ✅ |
| 31 | ReAct | Thought→Action→Observation, хрупок без fallback в инструментах | ✅ |
| 33-50 | техники | Function calling, LangChain, RAG | ⏳ |

## Запуск

```bash
git clone https://github.com/ТВОЙ_НИКНЕЙМ/prompt-diary
cd prompt-diary
pip install groq
```

Добавь свой Groq API ключ в `config.py` и запускай любой ноутбук.
